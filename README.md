# WeatherApp-React

Simple React weather app using OpenWeatherMap API and Vite.

## Setup

1. Install dependencies:

```bash
npm install
```

2. Start dev server:

```bash
npm run dev
```

4. Open the app in the browser, enter a city name and click Search.

## Notes

- This app uses Vite's `import.meta.env` to access env variables prefixed with `VITE_`.
- Keep your API key private.
